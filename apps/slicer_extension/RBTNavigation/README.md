# RBTNavigation (planned 3D Slicer module)

V0.1: show rabbit brain MRI/CT, atlas labels, three orthogonal slices, 3D brain segmentation and reviewed *candidate* markers; support scene save/reload. Build as a Slicer ScriptedLoadableModule with Slicer MRML/Qt. No real robot motion APIs here. Slicer has a separate Python environment; do not blindly install the robot SDK inside it.
