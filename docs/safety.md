# Research safety boundary

This project is not a validated surgical system. Candidate hole and target markers are non-executable data. First-phase real robot interfaces must be read-only. No hardware motion, drilling, injection, or automatic tool changing through the navigation interface.

Motor current, conductance, vibration, sound, and force changes do not by themselves establish safe skull breakthrough. Start with inert phantoms and independent safety review. Animal experiments require ethics authorization and qualified specialist oversight. Physical interlocks and protective systems are separate from this software.
